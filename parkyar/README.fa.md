## چرا پارک‌یار؟

در بسیاری از پارکینگ‌ها شماره پلاک و زمان ورود هنوز دستی ثبت می‌شود. این کار کند است، خطا دارد و سابقه قابل اعتمادی باقی نمی‌گذارد. پارک‌یار این فرایند را خودکار می‌کند:

* دوربین‌های ورودی و خروجی پلاک خودروها را می‌خوانند.
* مدت توقف ثبت و هزینه طبق تعرفه پارکینگ محاسبه می‌شود.
* متصدی فقط پرداخت را تأیید می‌کند و رسید می‌دهد.

## امکانات

**ورود و خروج خودکار**
* پشتیبانی از وب‌کم و دوربین شبکه (RTSP)؛ برای نمایش می‌توان از فایل ویدیو یا عکس هم استفاده کرد.
* پلاک پس از دو بار خوانش یکسان ثبت می‌شود و یک خودرو دو بار پشت سر هم ثبت نمی‌شود.
* اگر یک نویسه پلاک اشتباه خوانده شود، خودروی درست خودکار پیدا می‌شود.
* اگر برای پلاکی ورودی ثبت نشده باشد، متصدی خودرو را از میان پلاک‌های مشابه انتخاب یا شماره را اصلاح می‌کند.

**محاسبه هزینه**
* تعرفه قابل تنظیم: مدت توقف رایگان، قیمت ساعت اول، قیمت هر ساعت بعد و سقف هر شبانه‌روز.
* نمایش زمان ورود، زمان خروج، مدت توقف و مبلغ، همراه با چاپ رسید.
* خودروهای مشترک تا پایان اعتبار اشتراک بدون پرداخت تردد می‌کنند.

**مدیریت**
* داشبورد زنده: تعداد خودروهای داخل پارکینگ، جای خالی، ورود و درآمد امروز و نمودار درآمد هفته.
* گزارش‌گیری با فیلتر تاریخ و پلاک، خروجی اکسل و امکان اصلاح هر ردیف.
* ثبت دستی ورود و خروج، تقویم شمسی، اعداد فارسی و پشتیبان‌گیری از اطلاعات.

## نسخه رایگان و فعال‌سازی

* پارک‌یار شامل **۱۰ تشخیص رایگان پلاک** است؛ ثبت دستی ورود و خروج شمرده نمی‌شود.
* برای استفاده نامحدود، از نوار کناری یا تنظیمات گزینه «فعال‌سازی» را باز کنید.
* شناسه رایانه را به [mehrdad.rahmani100@gmail.com](mailto:mehrdad.rahmani100@gmail.com) بفرستید و کد فعال‌سازی دریافتی را وارد کنید.
* هر کد فقط روی همان رایانه کار می‌کند.

## نصب

1. فایل [ParkYar-1.1.0-windows-x64-setup.exe](https://github.com/Mehrdadrahmani/persian-plate-recognition/releases/download/v2.2.0/ParkYar-1.1.0-windows-x64-setup.exe) را دریافت و اجرا کنید (ویندوز ۱۰ یا ۱۱، ۶۴ بیتی). نیازی به نصب پایتون نیست.
2. اگر پیام SmartScreen نمایش داده شد، «More info» و سپس «Run anyway» را بزنید.
3. برای اجرا از کد منبع در ویندوز، مک یا لینوکس، دستورهای زیر را اجرا کنید:

</div>

```bash
cd parkyar
pip install -r requirements.txt
python -m parkyar          # اجرای عادی
python -m parkyar --demo   # اجرا با داده نمونه
```

## توصیه‌های نصب در پارکینگ

* دوربین را طوری نصب کنید که پلاک در تصویر دست‌کم حدود ۱۰۰ پیکسل عرض داشته باشد و تار نباشد.
* رایانه‌ای با پردازنده هم‌رده i5 یا بالاتر کافی است؛ خواندن هر تصویر حدود ۴۰ میلی‌ثانیه طول می‌کشد.
* به‌طور منظم از بخش تنظیمات پشتیبان بگیرید.

## فناوری

* **پیدا کردن و خواندن پلاک:** مدل‌های بهینه‌شده (INT8) پروژه اصلی با حجم کل ۱۱ مگابایت، روی پردازنده رایانه.
* **رابط کاربری:** Qt با پشتیبانی کامل از فارسی و قلم وزیرمتن.
* **پایگاه داده:** SQLite.
